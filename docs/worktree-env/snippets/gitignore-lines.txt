Two notes.

1. `.claude/*` ignores the whole directory. If the repo wants to commit shared
   Claude config (agents, commands, a settings.json for everyone), use the
   narrower form instead:

       .claude/settings.local.json
       .claude/worktrees/

2. These patterns match at any depth. Anything you copy into the repo under
   one of these names gets swallowed, even inside a docs folder. That is why
   the sample files in ../files/ are named `env.worktree.example` and
   `docker-compose.override.example.yml` rather than their real names.

Machine-level, in ~/.config/git/ignore (already set on Pierre's machine, check
before adding):

    **/.claude/settings.local.json
    **/.claude/.cc-writes/
    **/.claude/worktrees/

The worktrees line is what lets worktrees live inside the repo directory
without every checkout seeing them as untracked junk.
